# Changelog

## 1.0.0 (2026-11-05)

First release.

### Added

- Visual workflow editor with undo and redo, autosave, validation, version history and auto layout
- 25 node types across triggers, logic, data, AI and integrations
- Execution engine with branching, loops, retries, timeouts, cancellation, error branches and node-level logs
- Test mode that simulates external side effects
- AI Workflow Builder with Claude, OpenAI and Gemini adapters, and a labelled demo planner
- Webhooks with signature verification, rate and size limits and a request log
- Database-backed schedules and job queue
- Encrypted credentials, SSRF protection, CSRF protection, roles, workspace isolation and audit logs
- Dashboard, execution history, inspector, comparison and analytics
- 8 workflow templates and a labelled demonstration workspace
- Windows setup and start scripts, Docker configuration and documentation
